A Workflow chains the steps of a month-end reporting pack: refresh the source data, run
the checks, build the summary reports and deliver the finished pack. The Scheduler runs it
early on the first day of each month, so the pack is waiting when the team arrives. The
run record shows each step as it starts and finishes, so a failed step is easy to find.
