# Concepts

A concept is a new idea for DataCrafter or a change to one of its specifications, written
as one Markdown file and proposed in its own pull request: one `.md` per pull request,
problem first, proposal second. The founder reviews it by comment. A merge means
"accepted into the backlog": it is a promise to consider the concept, not a promise to
build it. A merged concept may become a specification section or a concept document in
the product's own docs, and it is credited to you. See [CONTRIBUTING.md](../CONTRIBUTING.md)
for the rules and the CC BY 4.0 licence that applies.
